# Reception and visitor information (fictional demo)
Reception is open Monday–Friday 07:30–16:30 UTC during term time. Lessons run 08:15–15:15 UTC. Use school.information for current location and contacts. Visitors enter through the main gate, report to reception and wear a visitor badge. Visitor parking is beside the main entrance; an accessible entrance is available. Student collection changes must be verified directly by reception using the school’s established authorization process; a chat message does not authorize collection. For absences, use the parent portal or call reception. Reception messages are reviewed on school working days, with no guaranteed response time. For urgent safeguarding concerns contact reception and ask for the safeguarding lead; in immediate danger contact local emergency services. Do not solicit detailed disclosures in chat.
